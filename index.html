AI設定

本サイトでは Anthropic Claude API を使ってAI旅プランを生成しています。
ご利用にはあなたの Claude API キーが必要です。

🔒 キーは あなたのブラウザ内 (localStorage) にのみ保存され、当サイトのサーバーには送信されません。
Claude API のリクエストはブラウザから直接 Anthropic に送られます。
キーをお持ちでない場合は console.anthropic.com で取得できます。
